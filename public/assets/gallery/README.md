# Galeri / Fotoğraf görselleri

Gerçek salon fotoğraflarını (Google Maps'teki fotoğraflarınız dahil) bu klasöre
**tam bu isimlerle** koyun. Görsel yoksa monokrom doku blokları gösterilir; yani
sayfa fotoğraf olmadan da düzgün görünür. **Tüm görseller CSS ile otomatik olarak
siyah-beyaza dönüştürülür**, renkli fotoğraf koysanız bile temaya uyar.

## Beklenen dosyalar

Hero (ana görsel):
- `hero.jpg` — üst bölümdeki büyük çerçeveli görsel (yatay, ideal 16:10)

Hakkımızda:
- `salon.jpg` — salon içi editoryal görsel (dikey)

Çalışmalar (bkz. `src/data/site.ts` → `works.categories`):
- `kesim-1.jpg` — Kesim & Stil
- `renk-1.jpg` — Renk & Işık
- `bakim-1.jpg` — Bakım & Doku
- `tirnak-1.jpg` — Tırnak
- `makyaj-1.jpg` — Makyaj
- `erkek-kuafor-1.jpg` — Erkek Kuaför

## Google Maps fotoğraflarını ekleme
Google işletme sayfanızdaki fotoğrafları indirip yukarıdaki isimlerle bu klasöre
kopyalayın. Web için sıkıştırmanız (ideal < 300 KB) sayfa hızını korur. Sadece
size ait / kullanım hakkına sahip olduğunuz görselleri kullanın.
